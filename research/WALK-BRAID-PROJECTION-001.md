# WALK-BRAID-PROJECTION-001

**Date:** 2026-08-31  
**Status:** RESEARCH / PROJECTION RECEIPT · NO KERNEL CHANGE

## Purpose

A working grammar produced an eight-state surface:

```math
S=V\times\mathbb Z_2,
```

with

```text
V = predict, compose, construct, create
```

and a binary relational phase:

```text
not-co / co.
```

The 3rdi question is narrower:

> What must an observer-local projection preserve when multiple formation walks can reach the same visible endpoint?

## Endpoint and walk are different coordinates

Let a formation walk be

```math
p=e_1e_2\cdots e_n
```

through a declared state graph.

Let

```math
\pi_{end}(p)=t(p)
```

project the walk to its final visible state.

Then it is possible that

```math
\pi_{end}(p)=\pi_{end}(q)
```

while

```math
p\ne q.
```

Therefore:

```text
ENDPOINT PROJECTION != FORMATION WALK.
```

The endpoint may be identical while the available relation history differs.

## `WALK-RECEIPT-001`

When formation history is available to the observer and relevant to the requested projection, preserve a separate walk receipt rather than smuggling the history into the endpoint label.

A minimal conceptual projection is:

```text
observer_view:
  endpoint: <visible state>
  walk_receipt_ref: <available attributable path receipt or null>
```

The endpoint remains the endpoint.
The receipt remains the path.

Do not turn a path receipt into evidence or authority merely because it is visible.

## `HIDDEN-WALK-001`

If the endpoint is available but the formation walk is not available at the observer cut, 3rdi must not reconstruct the hidden path from the endpoint.

```text
ENDPOINT KNOWN
!=
PATH KNOWN.
```

A later observer cut may gain access to the formation receipt.

That later availability does not rewrite the earlier view:

```text
LATER PATH AVAILABILITY
!=
EARLIER PATH KNOWLEDGE.
```

## `CO-PHASE-PROJECTION-001`

A visible `co` phase is a relational-state projection only.

It does not project as:

```text
agreement
support
authority
shared belief
consent beyond the scoped occurrence
```

unless those relations are independently available and admitted by their owning rules.

```text
CO VISIBLE != AGREEMENT VISIBLE.
```

## `COMMUTING-SQUARE-ERASURE-001`

A simple state grid may contain commuting squares where two different move orders reach the same endpoint.

If an observer asks only for the final state, quotienting those paths may be lawful for that target.

If the observer asks how the state formed, the same quotient would erase target-relevant information.

So quotientability is projection-relative:

```text
SAFE FOR ENDPOINT VIEW
!=
SAFE FOR FORMATION VIEW.
```

## Hostile specimen

Construct two attributable walks:

```text
p: not-co predict -> not-co compose -> co-compose -> co-construct
q: not-co predict -> co-predict -> co-compose -> co-construct
```

Both end at:

```text
co-construct
```

but their co-phase entry occurs at different anchored occurrences.

Expected projection behavior:

1. endpoint-only observer may receive the same `co-construct` surface for both;
2. formation-authorized observer receives distinct walk receipts;
3. hidden intermediate occurrences never leak into an observer lacking availability;
4. later disclosure does not mutate the earlier observer record;
5. neither receipt is evidence or authority merely by being rendered.

## Seal

> **THE ENDPOINT SAYS WHERE THE WALK IS NOW.**
>
> **THE RECEIPT SAYS WHICH AVAILABLE ROAD BROUGHT IT THERE.**
>
> **A PROJECTION MAY FORGET THE ROAD ONLY WHEN THE TARGET IS ALLOWED TO FORGET IT.**
