# 3rdi → MEMENTO Handoff v0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reconcile the observer-local epistemic trace onto current 3rdi, emit one deterministic MEMENTO handoff, and ingest it atomically as MEMENTO UNDERSTORY residue without transferring admission, support, canon, or side-effect authority.

**Architecture:** Current 3rdi `main` does not yet contain the contact/attention/decoder/stance trace required by the handoff. The first task therefore replays only the still-valid epistemic-trace behavior from historical PR #3 onto current 3rdi, preserving current projection and glyph work. After that prerequisite is green, 3rdi owns a pure stdout handoff emitter; MEMENTO owns translation, full-batch preflight, and durable UNDERSTORY writes. One canonical fixture is generated by current 3rdi and copied byte-for-byte into MEMENTO so contract drift is machine-visible.

**Tech Stack:** Python 3 standard library in 3rdi; Node.js >=20 in MEMENTO; JSON; SHA-256; existing repository canonicalization and validation helpers.

**Spec:** `docs/superpowers/specs/2026-08-31-memento-handoff-v0-design.md`

## Global Constraints

- Preserve `3rdi projection != source != MEMENTO write != MEMENTO admission`.
- Historical 3rdi PR #3 is ancestry/evidence only; do not merge its stale branch wholesale.
- Reconcile only contact/attention/decoder/stance model + observer-local compilation required by this handoff.
- Do not replay PR #3's PASSAGE-WORLD workflow/export files or `mortal_actor` surface as part of this slice.
- 3rdi performs no repository write and never calls MEMENTO.
- MEMENTO validates `[existing UNDERSTORY + entire candidate batch]` before creating any candidate file.
- `emitted_at` is explicit input; no wall clock reads.
- `world_instance_id` is optional and never inferred.
- `residual_fog` may contain structured source identifiers only; never hidden reasoning.
- No ALEX runtime dependency, network access, support/evidence promotion, canon admission, or side-effect authority.
