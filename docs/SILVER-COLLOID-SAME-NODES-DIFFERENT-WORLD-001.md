# SILVER-COLLOID-SAME-NODES-DIFFERENT-WORLD-001

**Status:** research projection specimen · no kernel change  
**Date:** 2026-08-29

> **Same local nodes can participate in different relational worlds, and the projection can change without rewriting occurrence.**

---

## 0. Why this belongs in 3rdi

3rdi distinguishes carrier, decoder, projection, occurrence, availability, focus, and relation history.

A silver-colloid ensemble supplies a physical specimen where local particle constitution can be held approximately fixed while relational topology changes.

The useful distinction is:

```text
local particle state
!= colloidal relation graph
!= optical coupling graph
!= measured optical projection
```

This is not a claim that silver colloids possess memory or that an optical spectrum is canonical truth.

It is a clean observer-local test of:

```text
same local inventory
+ different relations
-> different lawful projection
```

## 1. Two-world construction

Construct two worlds `W_A` and `W_B`.

Hold approximately constant:

```text
particle count / concentration
particle size distribution
particle shape distribution
material identity
surface ligand chemistry
solvent
ionic composition
measurement geometry
illumination settings
```

Change only the target relational organization as far as practicable:

```text
W_A: dispersed / weakly coupled
W_B: dimer- or chain-rich / more strongly coupled
```

Then:

```text
X_A ~= X_B
G_A != G_B
```

where `X` is local-node constitution and `G` is the relevant relation graph.

The observed projection may satisfy:

```text
P(W_A) != P(W_B).
```

If so, the difference belongs to the constituted world/projection relation, not automatically to any single node.

---

## 2. Preserve two graphs

Do not collapse:

```text
G_colloid
```

with

```text
G_optical.
```

`G_colloid` may encode aggregation/contact/electrostatic or steric interaction relations.

`G_optical` may encode plasmonic/electromagnetic coupling weights depending on separation, orientation, frequency, dielectric environment, and particle shape.

A pair of particles can be close enough to interact colloidally without having the same optical edge weight under every observer wavelength/polarization.

Thus:

```text
RELATION TYPE IS PART OF THE DECODER.
```

---

## 3. Observer-local projection

Let an observer be constituted by:

```text
O=(wavelength window,
   polarization,
   spectral resolution,
   spatial aperture,
   time cut,
   calibration,
   relation decoder).
```

Then the measured view is:

```math
V_O(W)=P_O(X,G,E).
```

Different observers may receive different lawful projections from the same physical occurrence.

Example:

```text
observer O1: UV/visible extinction
observer O2: DLS / hydrodynamic size
observer O3: microscopy
observer O4: ion-speciation assay
```

None is the whole world.

Each projection answers a different typed question.

## 4. Occurrence does not rewrite when relevance changes

Suppose an aggregate forms at `t0`.

Later, a newly chosen optical wavelength makes that aggregate strongly diagnostic.

Then:

```text
occurrence_time = t0
availability_of_measurement = later instrument/readout time
attention_role = when investigator chooses the feature
relevance = may increase later
```

But:

```text
causation does not move to the later relevance time.
```

This makes the specimen a physical analogue of the 3rdi constitutional invariant:

> Occurrence is anchored. Availability changes. Attention moves. Relevance can grow. Causation does not rewrite itself.

## 5. Same nodes, different world is stronger than same scalar

A weak comparison would be:

```text
same total silver concentration
```

because many hidden variables can differ.

A stronger comparison is a controlled two-world pair:

```text
same node-local constitution within tolerance
same medium constitution within tolerance
same observer
only intended relation graph differs
```

Then the projection delta is attributable to a narrower cause family.

This is a two-world property:

```text
observer truth about relation dependence
requires comparing worlds that differ in the hidden relation.
```

## 6. Projection blindness control

If an observer wavelength is insensitive to a particular separation/orientation change, then:

```text
P_O(W_A)=P_O(W_B)
```

may occur even when

```text
G_A != G_B.
```

Therefore:

```text
SAME PROJECTION != SAME WORLD
```

and conversely:

```text
DIFFERENT PROJECTION != DIFFERENT LOCAL NODE IDENTITY.
```

This is the core 3rdi value of the specimen.

## 7. Formation-history extension

Two ensembles may produce similar present spectra while having different formation histories:

```text
slow reversible dimerization
vs
rapid salt-triggered aggregation
```

If present projection collapses those histories, preserve:

```text
surface similarity
!= formation identity.
```

A later discriminator may reopen the distinction.

This specimen therefore composes naturally with formation trace but does not make formation history visible unless an observer actually measures a consequence of it.

## 8. Decoder-sensitive relation threshold

Colloidal interaction reach can change with medium constitution. In a simple electrolyte model:

```math
\lambda_D\propto I^{-1/2}.
```

So a distance that counts as strongly electrostatically coupled under one ionic strength may be effectively screened under another.

The geometric separation can remain the same while the lawful relation changes.

Therefore:

```text
GEOMETRY ALONE != RELATION.
```

Relation is typed by constitution.
