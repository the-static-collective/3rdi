# 3rdi

**See from somewhere without pretending it was everywhere.**

`3rdi` is a provenance-first projection organ. It compiles an observer-local view while leaving the witnessed field alone.

Hold one sentence through the run:

> **Occurrence is anchored. Availability changes. Attention moves. Relevance can grow. Causation does not rewrite itself.**

Never collapse:

```text
occurrence != availability != attention role != relevance
relevance != causation
carrier != decoder != projection
projection != source != authority
historical cut != current hindsight
actual future != anticipated future
visible != traversable != admitted
gate result != side effect
```

## Pick the smallest eye

| Mode | Use it for |
|---|---|
| `CUT` | One observer at one temporal/knowledge horizon |
| `PARALLAX` | Compare observers, cuts, audiences, locations, or decoders |
| `REINTERPRET` | Apply a new decoder without overwriting the old projection |
| `GATE` | Evaluate pure `pass | fail | unresolved` admission conditions |
| `LAB` | Try to break the projection with a hostile control |

Do **not** wake `3rdi` for ordinary summarization, a simple chronology, generic graph analysis, or to turn an attractive interpretation into evidence.

## Run the aperture

`LOCATE -> CUT -> DECODE -> GATE -> PROJECT -> PRESSURE -> RECEIPT`

1. **LOCATE** — name the owner question, source cut, observer/audience, `focus_at`, `known_at`, decoder constitution, and authority boundary.
2. **CUT** — keep occurrence time on occurrences and availability on exposure receipts. Historical mode forbids `known_at > focus_at`.
3. **DECODE** — preserve `CARRIER -> DECODER RECEIPT -> PROJECTION -> FORMATION TRACE`. A new decoder creates a descendant projection.
4. **GATE** — gates are pure predicates. A result never sends, writes, admits, or authorizes anything by itself.
5. **PROJECT** — emit only observer-visible content. Keep causal and relevance ledgers separate. Edge existence is not global edge availability.
6. **PRESSURE** — run the smallest control that could falsify the result: earlier cut, second observer, alternate decoder, shuffled chronology, frozen causal ledger, or metaphor removal.
7. **RECEIPT** — return the requested projection plus decisive cut coordinates, decoder receipts, causal/relevance results, gate states, hindsight/freshness notices, withheld categories, residual fog, and verification evidence.
